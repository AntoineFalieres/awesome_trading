# Specification for MM30 Indicator (Weinstein's Moving Average)

## Context
The MM30 (Mansfield/Weinstein Moving Average) is the core trend-definition tool for the "TrendFlow" app. It identifies the 4 stages of a stock's lifecycle. We are implementing a **Weighted Moving Average (WMA)** to prioritize recent price action, as defined in the Constitution.

## Target File
`src/indicators/mm30.py`

## Dependencies
* `src/indicators/base.py` (Must inherit from `Indicator` class)
* `numpy` (for weighted calculation)
* `pandas`

## Requirements

### 1. Class Structure
* **Class Name:** `MM30Indicator`
* **Parent:** `Indicator` (from `src.indicators.base`)

### 2. Configuration (`__init__`)
* **Parameters:**
    * `period` (int, default=30): The lookback window.
    * `source` (str, default='close'): The column to average.

### 3. Implementation Logic (`calculate`)
* **Input Validation:** Call `super().validate_input(data)` first.
* **Math Formula (WMA):**
    * Do **NOT** use a Simple Moving Average (SMA).
    * Do **NOT** use an Exponential Moving Average (EMA).
    * **Algorithm:**
        1. Create a weight array: `[1, 2, 3, ..., 30]`.
        2. Use `pandas.rolling()` with the window size matching the period.
        3. Apply the dot product of the window slice and the weights, divided by the sum of weights.
        * *Optimization Note:* Use `raw=True` in `apply()` for speed if using a lambda, or use pure numpy convolution if possible.
* **Output:**
    * A Pandas Series named `mm30`.
    * Ensure the series index matches the input DataFrame.

### 4. Visualization Metadata
* Add a method or attribute `plot_config` that returns:
    * `color`: 'orange'
    * `style`: 'line'
    * `overlay`: True (plots on top of price)

### 5. Error Handling
* If the input DataFrame has fewer rows than the `period`, return a Series of `NaN`s (do not crash).
